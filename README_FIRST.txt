# CC Motocrafts — audited source package

Start page: `index.html`
Customer portal: `customer.html`
Partner portal: `partner.html` (same supplied interface as `garage.html`)
Operations: `admin.html`
Owner: `owner.html`

Read `PRODUCTION_AUDIT.md` before deployment. This is an audited front-end package, not a finished production platform. Do not enter real customer data or use the embedded demo passcodes on a public deployment. A real backend and server-side authorization are mandatory.

No DNS, nameserver, MX or email-hosting settings are included or changed by this ZIP.
